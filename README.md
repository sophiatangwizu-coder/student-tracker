# 紫笺 · 学生跟踪工作台

直接双击 `index.html`，使用 Chrome、Edge 或 Safari 打开。保持 `index.html`、`app.js`、`core.js`、`workflows.js`、`analytics.js`、`style.css` 和 `vendor` 文件夹在一起。无需安装、账号或网络。

若浏览器限制本地文件存储，可在本目录运行 `python3 -m http.server 8765`，再打开 http://localhost:8765 。之后保持同一地址和浏览器使用。文件方式与 localhost 的数据互相隔离，可通过完整备份迁移。

## 开始使用

1. 导入学生名单：下载 Excel 模板，填写「班级、姓名、学号、性别」，导入后预览并确认。班级会自动创建。也可手动添加。
2. 新建默写、小测或作业；班级当前在读学生自动加入本场。
3. 默写默认 p；p- 权重 0.5，但无需重默。只有 f 需要重默，重默不改变首次通过率。订正默认正确。免默与未参加分开登记，均不计入通过率；免默无需重默或本次订正。
4. 默写表中的「上次订正」指同班按日期、创建先后排序的上一场；「详情」可修改本次订正。
5. 小测先设置总分，再录入或导入成绩。支持总成绩及可选题型分项；学生档案和「小测 → 成绩分析」可切换得分率对比与总成绩年级名次，缺考及空白不计入。
6. 作业默认完成，可选未完成、待改、免交；已补交与已改在右侧跟进栏并列登记，支持备注和多张图片。
7. 学生档案可按日期范围导出 Excel，或预览并打印成 A4 PDF，两者均可选择作业、默写、小测或全部。数据管理的 Excel 导出也提供这四种选择。勾选「附上作业图片」可将图片附入报告。

## 场次列表与快捷名单

- 点击左侧默写、重要作业或小测，先进入独立的场次列表。可按名称、班级、日期范围及待处理进度筛选，按日期或名称排序，每页 20 场。
- 点击名称或「进入详情」登记学生情况；「返回列表」保留本模块的筛选条件和页码。切换详情页顶部的班级会返回列表，重新选择场次。
- 默写详情支持复制首次未通过、待重默、本次订正待处理名单；首次未通过名单包括后来重默已通过者，待重默名单则排除重默已通过者。
- 作业详情支持复制仍未完成、待改、已改名单；已补交的学生不再出现在「未完成」名单中。
- 小测支持复制本场班级最后 5 名，只统计有效成绩，真实 0 分计入，缺考和未录入排除。成绩从低到高排列；同分按学号、姓名及内部 ID 稳定取足 5 人，不足 5 人时复制所有有效学生，不扩展并列人数。
- 每个详情页也支持「复制当前筛选」。其他快捷按钮始终按本场全班选取，不受表格筛选影响。
- 复制内容含班级、日期、场次、名单类型及姓名，不包含分数。同名学生附学号；未填学号时附本场名单序号。无匹配学生时不修改剪贴板；浏览器不允许自动复制时显示可手动复制的文本。

## 作业订正

- 「待改」表示作业已交但学生需要订正，暂不计为完成；「已改」表示订正完成，计入完成率。
- 原本未完成的作业选择「待改」后，自动标记为已补交并保留原始未完成记录及补交日期。在右侧勾选「已改」并记录日期，下拉框仍保留「待改」。旧版已改数据自动按这一形式展示。
- 重新选择「未完成」或取消「已补交」，会清除当前订正状态，重新进入未完成名单；选择完成或免交也会清除订正状态。
- 待改出现在总览待办、场次进度、学生筛选与复制名单中。学生档案、Excel、PDF 和完整备份同步保留订正状态及补交历史，旧版备份仍可恢复。

## 小测趋势、跨班统计和性别

- **得分率（默认）**：得分 ÷ 当次总分 × 100%，纵轴固定 0–100%。不同总分的小测优先用此指标比较，但试卷难度变化也会影响曲线。
- **总成绩年级名次**：第 1 名位于图表最上方，向上表示名次进步。鼠标悬停或键盘聚焦可查看原始得分、总分和「年级名次 / 有效成绩人数」。班级名次保留在成绩表中。不同场次人数变化时，应结合人数解读名次。
- 同分使用竞赛排名：例如 1、2、2、4。缺考、未录入不排名，也不计入平均分；真实 0 分参与统计。尚有成绩未录入时，均分和排名标注为暂定。
- 新建小测默认独立统计。其他班级使用同一份试卷时，在「同一场跨班小测」选择加入已有场次，总分、名称和分项满分自动填入，实际考试日期可另选。
- 已有记录可在小测页面点击「跨班关联」，选择对应场次，或解除当前班级的关联。仅关联同一份试卷；不同总分、同班重复、学生跨班重复均被阻止。旧记录不会因同名或同日自动合并。
- 年级是**同一场小测所有已关联班级**的合并结果，不受页面班级筛选影响。页面明确列出参与班级；只关联了一个班级时暂时只有本班的数据。
- 小测顶部显示班级、年级、班级男生、班级女生平均分及有效人数。年级均分 = 各班有效成绩总和 ÷ 有效成绩总人数，不是班级均分的简单平均。表格搜索和筛选不改变统计范围。
- 名单模板新增可选「性别」列：填写男、女或未填写；也可以在学生资料里修改。旧名单默认未填写，计入整体均分，不计入男、女生分组。
- 批量补充已有学生性别：导出名单，填好性别，再导入并勾选「仅更新已有学生性别」。按班级＋学号匹配，无学号时按唯一姓名匹配；不会新增学生或覆盖学习记录。
- Excel 小测明细带上名次、平均分、有效人数和关联班级；PDF 报告使用档案中所选题型和场次，可切换得分率或总成绩年级名次，并保留班级、年级名次明细。

## 学生档案的小测展示

学生列表、个人摘要和逐次小测明细显示年级名次，成长曲线默认显示总成绩年级名次。未关联其他班级时显示“未关联”，不将班级名次当作年级名次。需要题型得分率及均线比较时，仍可在图表中主动切换得分率模式。学生报告和 Excel 概览同步使用年级名次。

## 题型分项与成绩分析

- 新建小测时展开「题型分项」，或在小测详情点击「题型分项」。需要的题型填写满分，其余留空；支持不分项、部分分项、全部 13 项。各场满分可以不同，同一关联场次的同名分项满分必须一致。
- 题型包括：听力短对话、听力篇章、听力长对话、语法填空、小猫钓鱼、完形填空、阅读A、阅读B、阅读C、六选四、翻译、小作文、大作文。
- 总成绩独立录入，不由分项自动求和。下载模板包含本场已设置题型；也可只提供姓名或学号及部分题型列进行补充导入。空白和缺少的列不覆盖旧成绩，数字 0 正常录入；要清空分项，在网页中清空对应输入框。
- Excel 导入先检查学号、重复行、分数范围和满分配置，预览列出将更新的成绩；确认后保存。缺考学生不参与分项统计，取消缺考后才能录入分项。
- 「查看题型分项均分」默认折叠，展开显示所有分项班级均分、平均得分率及有效人数；「登记 / 查看学生分项成绩」可直接编辑。已有成绩的分项不能移除或将满分降到低于现有得分。
- 小测详情的「融合排名」将全部关联班级学生合并，按总成绩年级名次排列，可搜索、按班级筛选和导出 Excel；筛选不改变排名。
- 「小测 → 成绩分析」可选择多个学生，或最多两个班级；支持搜索对象、多选场次、日期范围和单选总成绩 / 一个题型。跨班比较仅显示覆盖所选对象的关联小测，按组内最早日期排序，同组只占一个横轴位置。
- 学生得分率图默认同时显示学生曲线、所在班级平均得分率及年级平均得分率；两种均线可独立勾选，选择仅看班级、仅看年级、同时看或只看学生曲线，同班基准线去重。打印报告沿用当前均线选择。名次模式始终锁定总成绩，不计算分项名次。不关联时年级曲线留空。
- 班级对比可切换班级均分或班级平均得分率。均分模式显示满分，不同满分建议使用平均得分率。年级均分按有效学生汇总，不直接平均各班均分。
- 缺考、未录入、未设置的题型留空并断线，不补零；明细显示各班日期、满分、有效人数和数据未齐提示。改变所选场次会改变进步比较基准，选择题型不会改变总成绩名次的口径。
- 成绩分析可以打印当前图表与场次明细。学生报告使用档案中已选的题型和场次绘图，完整逐次记录仍保留日期范围内全部记录。Excel 导出新增分项得分、满分、均分、有效人数及名次进步的比较场次。
- 完整备份包含分项配置、成绩、图片及作业跟进。旧版小测没有分项时继续按总成绩使用，无需补录。

## 自定义工作台名称

点击左上角名称旁的编辑图标，或进入「数据管理 → 工作台名称 → 修改名称」。填写 1–20 个字符后保存，名称会同步到页面标题和报告署名，刷新后保留，并随完整备份迁移。旧版本备份未包含名称时，恢复为默认名称「紫笺」。

## 本地保存与备份

- 数据及图片保存在当前浏览器的 IndexedDB；每次完成字段编辑（离开输入框）自动保存。观察右上角保存状态。
- 定期在「数据管理」导出完整 JSON 备份。清除网站数据、更换浏览器或地址之前务必备份。
- Excel 导出用于查看明细，**不包含图片本体**；完整备份包含全部图片。
- 恢复会替换当前全部数据，恢复前会显示摘要并要求勾选确认。
- 不要多窗口同时编辑；检测到其他窗口已写入时会拒绝覆盖，请先备份未保存内容，再刷新。
- 图片支持 JPG、PNG、WebP，每张最大 20 MB，保存时压缩到最长边 1600 像素。
- 学生可停用，历史记录保留；新增学生不会补入旧活动。历史活动保留原班级。

## 统计口径

- 默写加权通过率 = (p 次数 + p- 次数 × 0.5) ÷ 实际参加次数；未参加、免默排除。
- 小测得分率 = 分数 ÷ 当次总分（分项则用分项满分）。进步幅度 = 上个已选有效可比场次的总成绩年级名次 − 本次名次；正数表示进步。仅比较均关联至少两个班且班级集合相同的场次，显示比较场次和参评人数；无可比记录显示“暂无可比数据”。未主动选场次时使用当前日期范围内全部小测。
- 作业完成率 = 已交且无需订正或已改的次数 ÷ (总次数 − 免交次数)。待改暂不计入分子；另列初次未完成、补交、待改和已改次数。
- 总览待处理卡片按学生去重，展开后列出每场待办。

## 技术

原生 HTML/CSS/JavaScript，IndexedDB 分表及事务保存，原生 SVG 趋势图，无运行时网络请求。Excel 使用本地 SheetJS CE 0.20.3，许可证见 `vendor/SheetJS-LICENSE.txt`。

运行领域逻辑测试：`node tests/core.test.cjs` 、`node tests/quiz.test.cjs`、`node tests/workflows.test.cjs` 和 `node tests/analysis.test.cjs`。浏览器回归脚本位于 `tests/`，可通过 `PLAYWRIGHT_PATH`、`CHROME_PATH` 指定测试依赖和浏览器。
